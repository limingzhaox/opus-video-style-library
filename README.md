## 内容与来源

Lemo 的 STYLE.md 保留完整作者原文；18 项手作模板根据作者引擎说明整理，并非作者原始对话。中文任务模板由资料库整理。使用时须另行克隆对应完整上游工程，交给可运行代码的 AI，并按指南检查环境、声音、素材与短片预览。

主要来源：[LemoLab](https://github.com/lemomo-ai/lemo-opuscar)、[Miranda Dixon-Luinenburg](https://github.com/cyborggirl963/opus-5.5-music-video-art-styles)。保留 MIT 文档许可；Lemo 示例图片按 CC BY 4.0 署名，图片经过缩放与编排；第三方素材与三项示例声音有例外，请先阅读完整署名页。

## 仓库与部署

仓库中的 site.zip 是可审查、可离线解压的完整静态资料包。GitHub Actions 将其解压后部署到 GitHub Pages；每个 prompts/*.md、JSON 与原文快照都可从站点独立读取，无需运行网页脚本。ZIP 内含公开文档、来源版本、许可证、构建和检查脚本，不含原始 PDF、个人修改目录、凭据或本机配置。

每周二 10:00（Asia/Shanghai）由本地 Codex 维护任务核对上游，审查变化并更新资料包，再部署站点。需要本机与 Codex 运行；这不是承诺始终在线的云端采集服务。静态网站部署后不依赖本机开机，外部访客仍可访问。
